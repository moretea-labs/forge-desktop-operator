# Support

Use this repository's Issues for reproducible Forge Desktop Operator bugs and provider-specific feature requests.

For Forge setup, plugin installation, Controller behavior, or cross-provider questions, use [Forge Discussions](https://github.com/moretea-labs/forge/discussions) or the [Forge support guide](https://github.com/moretea-labs/forge/blob/main/SUPPORT.md).

Security vulnerabilities must not be posted publicly; follow [SECURITY.md](SECURITY.md).
